当储能有了"人格"：用 PersonaLLM 驱动微电网 Multi-Agent 调度

博客 10 · W11 成果 · 电力电子学习笔记

引子：一个微电网，四个"员工"

假设你是一家微电网的运营者。每天早上，你需要回答三个问题：

  1. 今天光伏能发多少电？
  2. 负荷要用多少电？
  3. 储能电池该怎么充放电，才能既省钱又不伤害电池？

传统做法是一个大脑集中决策：把所有数据喂给一个优化算法，算出最优解。

但真实的电力系统不是这样的。真实的市场里，光伏电站、储能运营商、负荷用户都是独立的利益主体，它们通过价格信号互相协调，而不是听从一个中央命令。

这正是本周我要做的事：用 Multi-Agent（多智能体）框架，让微电网里的每个设备"活"起来，拥有自己的角色、工具，甚至人格。

一、四个 Agent，各司其职

我基于 AutoGen 框架（微软开源的多智能体框架）搭了一个微电网调度系统，定义了四个角色：

Agent职责工具箱
光伏 Agent光伏发电的"眼睛"查询预测出力、实际出力
储能 Agent电池的"管家"查询 SOC、充放电功率限制
负荷 Agent负荷的"代言人"查询负荷预测
调度 Agent全局"决策者"查询电价

每个 Agent 有两个关键要素：

  1. 角色描述（system_message）：告诉它"你是谁、你该做什么、不该做什么"
  2. 工具列表（tools）：给它能调用的 Python 函数

Agent 会在对话中自主决定何时调用工具获取数据。比如储能 Agent 被问到时，会自动调用 get_soc() 拿到 SOC，再基于数据回答。

💡 关键点：Agent 不是被动执行，而是"带着目的"去查数据、做判断。这背后是 LLM 的 function calling 能力——模型能理解"我需要先查 SOC 才能回答"。

二、报价-协商-执行：让 Agent 讨价还价

光有角色还不够。真实的协调需要价格信号。于是我在四个 Agent 之间加了一套"报价-协商-执行"协议。

场景：上午 11 点，光伏过剩 6 kW，储能 SOC 偏低 30%，负荷 6.5 kW。

对话是这样展开的（真实 DeepSeek 驱动）：

储能 Agent：我报充电服务价 0.45 元/kWh
           （以售电价 0.2 为底线、购电价 0.6 为上限，我赚差价）

调度 Agent：还价 0.30 元/kWh
           （弃光的边际价值只有 0.2 元，0.45 太高了）

储能 Agent：接受 0.30 元/kWh
           （正好在我可接受的底线，且 SOC 低充电对我也有利）

调度 Agent：执行！储能充 2.5 kW，负荷直供 6.5 kW，剩余 5 kW 弃光

两个 Agent 居然真的讨价还价了，而且逻辑专业得让人意外：

  • 储能 Agent 分析了"弃光高峰期自己有谈判优势"，所以报了个偏高的价
  • 调度 Agent 用"弃光边际价值 0.2 元"来压价
  • 最终收敛到 0.30 元/kWh——一个双方都能接受的均衡点
💡 关键洞察：这个 0.30 元不是谁拍脑袋定的，而是价格信号协调的自然结果——既高于弃光价值（0.2），又低于购电价（0.6）。这就是去中心化市场的魅力。

三、PersonaLLM：给储能注入"人格"

前面的储能 Agent 是"理性经济人"。但现实中，不同运营者的风险偏好天差地别：

  • 有人保守：宁可少赚，绝不让电池冒险
  • 有人激进：只要有利可图，敢把电池用到极限
  • 有人均衡：折中行事

这就是 PersonaLLM 的思想：通过 system_message 注入人格化决策偏好，让同一个 Agent 在相同环境下做出不同决策。

我给储能 Agent 写了三种人格设定，喂给相同的电价场景（分时电价：峰 0.9 / 平 0.5 / 谷 0.2 元，初始 SOC 50%）。

结果差异显著：

人格SOC 区间决策风格
保守型 🛡️20%~80%只等 22 点低谷充电，放电止于 35%，"宁可少赚不冒险"
激进型 🚀10%~95%8 点就放空到 10%，12 点也敢充回 95%，"就是干！"
均衡型 ⚖️20%~90%分级放电保 20% 底线，充到 90% 留余量

最精彩的是，它们连自我解释都带着人格色彩：

  • 保守型列了一张"合规检查"清单，逐条验证 SOC 不触底线
  • 激进型逐笔算账"每度电净赚 0.4 元"，最后来一句"就是干！💪"
  • 均衡型解释"为什么 19 点不放电"——因为 15 点已到 20% 安全下限

四、人格的经济代价：一场 LP 精确的"算账"

定性描述人格差异还不够，我更进一步：把人格量化为约束，用线性规划精确计算经济后果。

直觉上，人格差异的本质是 SOC 约束差异：

  • 保守型 SOC ∈ [20%, 80%] → 可用容量小
  • 激进型 SOC ∈ [10%, 95%] → 可用容量大

用 scipy.linprog 求解三种人格在相同电价下的最大套利收益：

人格SOC 区间日收益可用容量
保守型20%~80%3.06 元3.6 kWh
均衡型20%~90%3.57 元4.2 kWh
激进型10%~95%4.32 元5.1 kWh

激进型比保守型多赚 1.27 元，代价是 SOC 跌到 10%——低于储能安全下限 20%。

💡 关键洞察：收益与安全是 trade-off。人格越激进，可用容量越大，赚得越多，但也越接近危险的边缘。这就是下一周要解决的"约束感知"问题的由来。

五、总结：从"一个大脑"到"一群有性格的 Agent"

本周完成了一次从集中式到分布式的范式跳跃：

集中式：所有数据 → 一个优化算法 → 最优解
分布式：多个 Agent → 价格信号 + 人格偏好 → 涌现的协调

三个核心收获：

  1. 价格信号是去中心化协调的关键——Agent 自主定价、讨价还价，收敛到均衡点
  2. 人格本质是可量化的约束——激进型多赚的钱，来自放松安全约束
  3. 收益与安全是 trade-off——这直接引出"约束感知 Agent"的研究问题

这套系统是 WukongAgent 的雏形。下一周，我要给它加上"安全层"：让 Agent 在追求收益的同时，绝不越界——这才是能真正投入电网运行的 Agent。
